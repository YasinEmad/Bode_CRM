# 📊 رسم توضيحي - مسار تدفق البيانات (Data Flow)

## 1️⃣ أول Check-in (First Login)

```
┌─────────────────────────────────────────────────────────────┐
│                     جهاز الموظف                              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  📱 التطبيق يضغط "Mark Attendance"                         │
│    ↓                                                         │
│  📍 قراءة الموقع (latitude, longitude)                      │
│    ↓                                                         │
│  🔑 توليد معرف جهاز فريد                                   │
│    └─→ deviceId = "abc123xyz..." (محفوظ في localStorage)  │
│    ↓                                                         │
│  📤 إرسال الطلب:                                            │
│     {                                                       │
│       latitude: 24.7136,                                   │
│       longitude: 46.6753,                                  │
│       deviceId: "abc123xyz..."                             │
│     }                                                       │
│                                                              │
└───────────────────────┬──────────────────────────────────────┘
                        │ HTTP POST
                        ↓
┌─────────────────────────────────────────────────────────────┐
│                      الخادم (Server)                        │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ✔️ التحقق من التوكن                                       │
│  ✔️ قراءة deviceId من الطلب                                │
│  ✔️ جلب بيانات المستخدم من DB                              │
│  ✔️ فحص: هل user.deviceId موجود؟                          │
│    ↓                                                         │
│  ❌ لا → حفظ deviceId الجديد                               │
│    user.deviceId = "abc123xyz..."                          │
│    user.save()                                             │
│    ↓                                                         │
│  ✔️ التحقق من الموقع (ضمن نطاق الجغرافيا)                 │
│  ✔️ حساب إذا كان متأخراً                                   │
│  ✔️ حفظ سجل الحضور مع deviceId                            │
│    ↓                                                         │
│  📝 Attendance {                                            │
│      userId: "user-id",                                    │
│      date: "2024-01-27",                                   │
│      deviceId: "abc123xyz...",                             │
│      checkInTime: "09:30:00"                               │
│    }                                                        │
│                                                              │
│  ✅ النتيجة: نجاح ✓                                         │
│                                                              │
└───────────────────────┬──────────────────────────────────────┘
                        │
                        ↓
┌─────────────────────────────────────────────────────────────┐
│                 جهاز الموظف (الرد)                          │
├─────────────────────────────────────────────────────────────┤
│  ✅ "Checked in successfully"                              │
│  💾 localStorage لا يزال يحتفظ بـ deviceId                 │
└─────────────────────────────────────────────────────────────┘
```

## 2️⃣ Check-in من نفس الجهاز (Same Device)

```
┌─────────────────────────────────────────────────────────────┐
│                     جهاز الموظف                              │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  📱 التطبيق يضغط "Mark Attendance"                         │
│    ↓                                                         │
│  📍 قراءة الموقع (latitude, longitude)                      │
│    ↓                                                         │
│  🔑 قراءة معرف الجهاز من localStorage                      │
│    └─→ deviceId = "abc123xyz..." (نفس المرة الأولى)       │
│    ↓                                                         │
│  📤 إرسال الطلب (نفس deviceId)                             │
│                                                              │
└───────────────────────┬──────────────────────────────────────┘
                        │
                        ↓
┌─────────────────────────────────────────────────────────────┐
│                      الخادم (Server)                        │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ✔️ التحقق من التوكن                                       │
│  ✔️ قراءة deviceId من الطلب: "abc123xyz..."               │
│  ✔️ جلب بيانات المستخدم من DB                              │
│  ✔️ فحص: هل user.deviceId موجود؟                          │
│    ↓                                                         │
│  ✅ نعم → المقارنة:                                        │
│    user.deviceId = "abc123xyz..."                          │
│    request.deviceId = "abc123xyz..."                       │
│    ↓                                                         │
│  ✅ متطابق → السماح بالتسجيل!                             │
│                                                              │
│  ✔️ التحقق من الموقع + الوقت                               │
│  ✔️ حفظ سجل الحضور                                        │
│                                                              │
│  ✅ النتيجة: نجاح ✓                                         │
│                                                              │
└───────────────────────┬──────────────────────────────────────┘
                        │
                        ↓
┌─────────────────────────────────────────────────────────────┐
│                 جهاز الموظف (الرد)                          │
├─────────────────────────────────────────────────────────────┤
│  ✅ "Checked in successfully"                              │
└─────────────────────────────────────────────────────────────┘
```

## 3️⃣ Check-in من جهاز مختلف (🔒 BLOCKED)

```
┌─────────────────────────────────────────────────────────────┐
│                     جهاز آخر مختلف                           │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  📱 موظف آخر (أو نفس الموظف من جهاز مختلف)                │
│  يمتلك كلمة السر ويحاول تسجيل حضور                         │
│    ↓                                                         │
│  📍 قراءة الموقع (latitude, longitude)                      │
│    ↓                                                         │
│  🔑 قراءة معرف الجهاز من localStorage                      │
│    └─→ deviceId = "xyz789def..." (جهاز مختلف)             │
│    ↓                                                         │
│  📤 إرسال الطلب:                                            │
│     {                                                       │
│       latitude: 24.7136,                                   │
│       longitude: 46.6753,                                  │
│       deviceId: "xyz789def..."  ← ⚠️ مختلف!               │
│     }                                                       │
│                                                              │
└───────────────────────┬──────────────────────────────────────┘
                        │
                        ↓
┌─────────────────────────────────────────────────────────────┐
│                      الخادم (Server)                        │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ✔️ التحقق من التوكن                                       │
│  ✔️ قراءة deviceId من الطلب: "xyz789def..."                │
│  ✔️ جلب بيانات المستخدم من DB                              │
│  ✔️ فحص: هل user.deviceId موجود؟                          │
│    ↓                                                         │
│  ✅ نعم → المقارنة:                                        │
│    user.deviceId = "abc123xyz..." (المحفوظ من قبل)        │
│    request.deviceId = "xyz789def..." (من جهاز مختلف)       │
│    ↓                                                         │
│  ❌ لا يتطابق! → رفض الطلب                                 │
│                                                              │
│  ❌ الخطأ:                                                  │
│     {                                                       │
│       "error": "Invalid device. You are trying to check    │
│               in from a different device...",             │
│       "reason": "DEVICE_MISMATCH",                        │
│       "status": 403                                        │
│     }                                                       │
│                                                              │
│  ⛔ رفض الطلب - لا حفظ لسجل الحضور                        │
│                                                              │
└───────────────────────┬──────────────────────────────────────┘
                        │
                        ↓
┌─────────────────────────────────────────────────────────────┐
│                 جهاز آخر (الرد)                             │
├─────────────────────────────────────────────────────────────┤
│  ❌ خطأ 403: Forbidden                                      │
│  رسالة: "جهاز غير صحيح - استخدم الجهاز المسجل معك"         │
│                                                              │
│  🔒 لا يمكن تسجيل الحضور بهذه الطريقة!                    │
└─────────────────────────────────────────────────────────────┘
```

## 📊 جدول المقارنة

| العملية | deviceId في DB | deviceId من الطلب | الحالة |
|--------|-----------------|------------------|--------|
| أول check-in | ❌ غير موجود | ✅ موجود | ✅ حفظ واسمح |
| check-in من نفس الجهاز | ✅ موجود | ✅ موجود | ✅ مطابق = اسمح |
| check-in من جهاز مختلف | ✅ "abc123" | ✅ "xyz789" | ❌ مختلف = رفض |
| بدون deviceId | ✅ موجود | ❌ غير موجود | ❌ مفقود = رفض |

## 🔐 الأمان (Security Model)

```
مستويات التحقق:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

المستوى 1: Token Authentication
   └─→ هل التوكن صحيح؟
        ├─ Yes → انتقل لـ المستوى 2
        └─ No → رفض (401 Unauthorized)

المستوى 2: Device ID Verification
   └─→ هل deviceId يطابق؟
        ├─ Yes → انتقل لـ المستوى 3
        └─ No → رفض (403 Forbidden) ⛔

المستوى 3: Location Verification
   └─→ هل الموقع ضمن النطاق؟
        ├─ Yes → انتقل لـ المستوى 4
        └─ No → رفض (400 Bad Request)

المستوى 4: Attendance Record Creation
   └─→ تم! حفظ السجل بنجاح ✅
```
