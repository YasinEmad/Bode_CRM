───────────────────────────────────────────────────────────────────────────────
🚀 كيفية البدء
───────────────────────────────────────────────────────────────────────────────

للمبيعات:
1. اذهب إلى "My Leads"
2. اختر lead وغيّر حالته إلى "Closed"
3. ملء جميع البيانات المطلوبة (16 حقل)
4. رفع صور الإثبات (يمكن رفع عدة صور)
5. اضغط "إغلاق الصفقة"
6. سيتم إرسالها للإدارة للموافقة

للإدارة:
1. اذهب إلى "Commission Management"
2. اضغط زر "Details" لأي عمولة
3. استعرض جميع بيانات الصفقة والصور
4. اختر "Approve" أو "Reject"

───────────────────────────────────────────────────────────────────────────────
📋 الحقول المدعومة (16 حقل)
───────────────────────────────────────────────────────────────────────────────

1.  TCR Type              → Dropdown (Reservation, Contract)
2.  Client Name           → Text Input (من Sales)
3.  Client Number         → Numeric Input (من Sales)
4.  Developer             → Text Input
5.  Unit Code             → Numeric Input
6.  Unit Area             → Numeric (sq.m)
7.  Unit Type             → Dropdown (15 خيار)
8.  Contract Price        → Currency
9.  Contract Date         → Date Picker
10. Finishing Type        → Dropdown (3 خيارات)
11. Delivery Date         → Year Picker
12. Payment Plan          → Dropdown (0-15 years)
13. Down Payment %        → Numeric (%)
14. Down Payment Amount   → Currency
15. Attachments           → File Upload (Multiple Images)
16. Info                  → Text Area
