# Contributing

Guidelines for contributing to this repository.

1. Work on a feature branch named `feat/your-short-desc` or `fix/your-short-desc`.
2. Keep commits small and focused; write clear messages.
3. Run the dev server and ensure the feature works locally.
4. Add tests where appropriate.
5. Open a pull request describing the change and any migration steps.

Code style: follow existing TypeScript and lint rules in the codebase.

If you need access to credentials or a staging DB, contact the project maintainer.
